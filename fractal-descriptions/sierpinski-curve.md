# Sierpinski Curve

A connected path repeatedly turns around square gaps. Its route becomes difficult to follow in a still image, although every stage keeps the same connections.

## Connections hidden by a dense path

The X symbols insert new detours. Existing F symbols remain forward moves. Right-angle turns organize the repeated square motifs.

<figure data-investigation="sierpinski-curve"></figure>

The square-based Sierpinski curve differs from the [triangular arrowhead](/l-system/sierpinski-arrowhead). Sharing a name does not give them the same replacement rule or limiting shape.

Compare the order of travel with the [Hilbert curve](/l-system/hilbert-curve). Both use a square grid, but their turns arrange the smaller routes differently.
