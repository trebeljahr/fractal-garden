# Adaptive spatial exploration

`SpatialExplorer` renders the Sierpinski tetrahedron and pyramid, polyhedron flakes, Jerusalem cube, both Koch surfaces, and 3D Hilbert curve. Their finite construction players continue using the existing scene and polyline renderers. The L-system Explorer is independent.

The camera stores a target in BigInt fixed point and a base-two zoom exponent. Precision grows with zoom, retaining 160 guard bits. Mesh vertices reach WebGL only after subtraction of the target. The limit is 240 zoom doublings; this is a practical depth bound. Input coefficients for irrational constructions retain the precision of the existing JavaScript generators.

Geometry builds in a worker, with at most one request running and the latest pending request retained. Conservative bounds include descendants: two edge lengths for triangular Koch patches, three half-widths for quadratic patches, and the seed circumradius for flakes and Jerusalem cubes. Frustum tests use planes before perspective projection. If a frame exceeds its geometry budget, the whole frame retries with a coarser screen tolerance; branches are never intentionally dropped from a displayed frame. Defaults are six CSS pixels and 120,000 triangle vertices.

The GPU depth buffer resolves overlap. Polygon outlines exclude fan triangulation diagonals. While a worker prepares detail, a change of camera frame transforms the last mesh immediately. Picking uses that same transform, so wheel gestures during refinement keep their model-space anchor. Context restoration recreates resources, and unmount terminates the worker and removes event listeners. Rendering requires WebGL and standard derivatives.

Flake children use the existing mesh vertices and contraction ratios. Jerusalem children have eight corner cubes at ratio `sqrt(2)-1` and twelve edge cubes at its square; their ranks advance by one and two respectively. Triangular Koch patches reproduce the existing midpoint tetrahedron construction. Quadratic patches reproduce eight flat squares and five raised cube faces. Hilbert octant symmetries are derived from the existing Skilling generator. Adaptive leaves join at the limiting octant endpoints.

`AttractorDetail` retains double-precision orbit checkpoints. Each user time interval uses four RK4 substeps. Its cubic Hermite segments use the differential equation at both endpoints and subdivide until projected midpoint and quarter-point deviations from the chord are at most 0.35 CSS pixels, within a bounded recursion and point budget. Bezier control hulls cull segments before projection, including intervals crossing the camera plane. Explicit break markers prevent drawing connections across culled intervals. Zoom adds later trajectory coverage up to 160,000 user intervals; normalization remains fixed to the opening orbit. Rendering retains at most 180,000 points. The camera allows 24 zoom doublings. This reveals more sampled flow, not an exact infinite attractor. Animated trails retain their existing finite-buffer behaviour.

Polyline picking runs in the existing render worker and returns a perspective-correct model point on a visible segment. The controls use this actual trajectory depth when zooming. Saved views include the fixed-point target and exponent, separately from the ordinary controls.

Mandelbulb uses the same target controls with a separate shader limit of twelve zoom doublings. The shader increases orbit iterations with zoom, up to 48, and allows 256 ray steps. Its world-space hit tolerance floors at `2e-7`; single-precision shader arithmetic bounds useful detail. CPU distance estimates anchor gestures to the visible surface. This is deeper numerical exploration, not arbitrary-precision Mandelbulb rendering.

Validation: `node --test tests/spatial-zoom.test.mjs`. The fixtures compare ray intersections with independent finite generators, unequal Jerusalem ranks, Hilbert endpoint continuity, deep camera coordinates, worker-frame transforms, trajectory coverage/refinement, perspective picking, and Mandelbulb surface anchors. Run `pnpm exec tsc --noEmit` and `pnpm build` after changes affecting the renderers or worker protocol.
